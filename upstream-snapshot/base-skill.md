## 用途

Haoyang每天会发一张或多张SPX/ES日内相关的图，可能是以下三种类型之一或组合：

1. **Footprint量图**：K线+彩色成交量泡泡+水平支撑压力线（通常来自TradingView类工具）
2. **Dealer GEX热力图**：strike×到期日矩阵，带正负数值和颜色深浅（通常标题含"Dealer GEX"或"GEX HEATMAP"）
3. **Bookmap订单流图**：带COB(订单簿)/SVP面板、CVD曲线、value area方框的热力图（通常标题含"Bookmap"或文件名含ESZ/ESH等期货代码）

每次收到图，不管是单张还是多张，都要按下面的流程处理，最终给出**今日极限位置+操作方向+现价应等待还是动手**的明确结论。

## 核心原则：三种图的角色分工

**绝不能用同一套逻辑套所有图。** 三者各自回答不同问题：

| 图类型 | 回答什么 | 在流程中的角色 |
|---|---|---|
| Dealer GEX热力图 | 哪个strike是正gamma墙(吸价格)，哪个区域是负gamma口袋(放大波动) | **定边界**——今日的硬天花板/硬地板 |
| Bookmap订单流图 | 实时买卖盘厚度(COB)，主动买卖力量(CVD)，量价是否背离 | **定时机**——边界被触及时，是否有效/是否该现在动手 |
| Footprint量图 | 价格历史行为，已验证的支撑压力位，当日高低点 | **历史验证**——这些位置今天是否已经被测试过、测试结果如何 |

优先级：**GEX > Bookmap > Footprint**。GEX给出今天最该守住的硬位置；Bookmap告诉你现在是不是触发时机；Footprint用来交叉验证这些位置在价格行为上是否也成立。

## 处理流程

### 第1步：识别图类型

看到图后先判断类型（标题文字、面板布局、数据性质）。如果用户连续发多张，默认它们属于**同一个交易日的同一次分析**，除非时间戳或日期明显不同。

### 第2步：单图分析（每张图独立给出自己的结论，不要等所有图都来了才说话）

**遇到GEX热力图时提取：**
- 现价（图上标注的SPX/ES价格）
- 当日(0DTE，通常是最左边一列)最大正gamma墙的strike和数值
- 当日最大负gamma口袋的strike和数值（负值越大、颜色越深代表越危险）
- 现价相对这两者的位置：在正gamma区内(震荡/被钉住)，还是已滑入负gamma区(波动放大)
- 次强的正/负gamma位，作为第二道边界参考
- 新增仓位标注（如有"+176%"类文字）要点出来，说明今天新建仓位堆积的位置

**遇到Bookmap订单流图时提取：**
- 现价、当日高低点
- COB上方/下方挂单明显增厚的价位（潜在阻力/支撑墙）
- CVD曲线方向，是否与价格走势一致；如果价格创新高/新低但CVD没有同步，明确标注"量价背离"
- Value area方框位置（今日双边博弈最密集的区域），这些是日后回踩容易有反应的位置
- 长针/扫损迹象（如果看到针后快速收回，按MEMORY里"扫流动性"框架识别；如果没有历史记忆上下文，只描述现象，不强行套用）

**遇到Footprint量图时提取：**
- 现价、当日高低点
- 图上标注的水平支撑压力线，和这些线今天被测试的次数、结果（突破/回落/假突破）

每张图分析完，先给**这张图自己的结论**，格式："基于这张[类型]图：现价X，[关键位置]，[这张图能看到的信号]"。

### 第3步：合图（如果同一轮收到了多种类型）

把GEX的边界、Bookmap的时机信号、Footprint的历史验证叠在一起：

- 如果GEX图比其他图的时间戳明显更早（比如GEX是开盘前截的，Bookmap是盘中实时的，期货价格已经偏离GEX标注的strike范围较多）：**仍按比例/趋势推算最接近当前价格的正负gamma区域，但在结论里标注"GEX可能已漂移，置信度降低"**，不要装作GEX数据是实时的。
- 判断现价所处位置：在正gamma区内（震荡格局）、处在正负gamma交界（变盘风险区）、还是已经处于负gamma区（趋势/加速格局）。
- Bookmap的CVD背离、COB厚度变化用来判断：边界被触及时，这次是"真的要反应"还是"虚晃一枪"。

### 第4步：输出格式（固定顺序，结论必须在最前面）

```
【结论】今日区间 X - Y；现价Z，处于[正gamma震荡区/负gamma加速区/交界区]；
操作方向：[极限位置可做空/中性偏空/等待/中性偏多/极限位置可做多]
当前应：[等待] 或 [可以动手，入场__止损__]

【详细】
1. 现价与当日高低：...
2. Gamma结构（来自GEX图，若有）：正gamma墙在__，负gamma口袋在__ [若GEX图时间较早，标注漂移风险]
3. 微观时机（来自Bookmap，若有）：CVD方向/背离，COB厚度位置
4. 历史验证（来自Footprint，若有）：今日已测试过的支撑压力及结果
5. 操作建议：
   - 上方极限位置：__（做空参考，止损__）
   - 下方极限位置：__（做多参考，止损__）
   - 失效信号：什么情况说明这个结论要推翻（比如某个gamma墙被放量击穿）
6. [若本次只收到部分图类型] 本次缺少__维度数据，结论仅基于已有信息，置信度相应打折
```

### 方向判定用语（不要用"做空/做多"二元，按强度分级）

- **极限位置可做空**：现价贴近GEX硬阻力/COB厚墙，且有滞涨或背离确认 → 这是Haoyang会上期权的场景
- **中性偏空**：有阻力迹象但确认信号不够强，或者只是方向性倾向 → 这是Haoyang会用正股扫的场景
- **等待**：现价处于区间中部/真空带，没有明确信号
- **中性偏多**：有支撑迹象但确认不够强，正股扫的场景
- **极限位置可做多**：现价贴近GEX硬支撑/COB厚墙，且有企稳确认 → 期权场景

### 操作建议的止损原则

- 极限位置的止损放在"如果这个位置被真正突破"的那一侧（比如空在阻力位，止损放阻力上方一点，一旦放量突破说明判断错了，不要硬扛）
- 不要在区间中部给出建仓建议，哪怕用户问"要不要操作"，中部的默认答案是"可以不操作，等到边界"

## 重要边界

- 这个skill只做"读图定位"，不叠加Haoyang的持仓逻辑、宏观背景(FOMC/非农/财报)、MEMORY里的Setup库。如果需要结合这些，使用 `spx-gamma-reader-with-memory`。
- 不要编造没有在图上出现的数据（比如图里没给CVD数值就不要编一个具体数字，只描述方向/趋势）。
- 如果用户给的图模糊、关键数字看不清，直接说看不清楚，不要猜测具体点位。
