## 用途

这是 `spx-gamma-reader` 的加强版：先执行完全相同的读图流程（GEX定边界、Bookmap定时机、Footprint历史验证），得到基础结论，再叠加Haoyang的MEMORY.md交易框架、当前持仓、以及当日宏观背景，给出更贴合他实际交易习惯的最终建议。

**使用前提：** 必须在能访问MEMORY.md的主会话场景使用（不在群聊/陌生人场景用），因为要调用个人持仓和交易框架信息。

## 第1部分：基础读图（直接复用 spx-gamma-reader 的流程）

按 `spx-gamma-reader` skill中定义的完整步骤执行：
1. 识别图类型（GEX热力图/Bookmap订单流/Footprint量图）
2. 每张图独立给出单图结论
3. 合图：GEX定边界，Bookmap定时机，Footprint做历史验证；GEX时间较早时按比例推算并标注漂移风险
4. 得到基础版的【结论】和【详细】五项（现价高低/Gamma结构/微观时机/历史验证/操作建议）

这一部分的输出格式和用语分级（极限位置可做空/中性偏空/等待/中性偏多/极限位置可做多）完全照搬，不要重新发明。

## 第2部分：叠加层（这个skill独有的增量）

拿到基础结论后，再检查以下几件事，追加到结论里：

### 2.1 查当日宏观背景
- 查今天是否有FOMC/非农/CPI/重大财报等事件（如果不确定，可以用web_fetch查一下当天日历，或者直接问Haoyang今天有没有特殊事件）
- 对照MEMORY里的"开盘前检查清单"：如果今天有这类事件，均值回归类的判断要降权，图上显示的"正gamma震荡"可能随时被新闻打破
- 对照Setup 9（AI Mini-Cycle Phase识别）：如果最近有大型财报（NVDA/Meta/MSFT等），判断当前处于哪个Phase，Phase 5尾声阶段时，即使图面显示健康也要加一句提示

### 2.2 查当前持仓
- 读MEMORY.md里"当前持仓"部分，看Haoyang现在手上有没有相关仓位（标的、方向、止损位、失效条件）
- 如果基础结论的方向与现有仓位一致：提示"与现有仓位同向，可以作为加仓/维持参考"
- 如果方向相反：明确提示"与现有仓位[标的]方向冲突，建议先确认那个仓位的逻辑是否还在，而不是忽略冲突硬开新仓"（对应MEMORY里"两个仓位逻辑独立"的教训和心理账户错误案例）

### 2.3 关联已识别的行为弱点
检查这次给出的建议是否撞上MEMORY"已识别行为弱点"里的任何一条，如果撞上就提醒一句：
- 如果刚经历大亏，提醒"大亏后过度交易"风险，建议先冷静
- 如果建议集中在同一个标的/同一方向加仓，提醒"高集中度风险"
- 如果是震荡市用的fade逻辑，提醒"忍一忍"习惯在新闻驱动行情会放大亏损，先确认今天不是新闻日

### 2.4 关联相关Setup
如果今天的图面结构明显对应某个已有Setup（比如负gamma区+科技股财报季，对应Setup 9；或者扫损后快速收回，对应交易感悟录第10条），在结论最后点出"这个情况类似你的Setup X"，但不要牵强关联，没有明显对应就不提。

## 最终输出格式

```
【结论】[与spx-gamma-reader相同的一句话结论]
[新增]：与当前仓位[一致/冲突/无关]；[今日是否有宏观事件影响判断]

【详细】
1-5. [与spx-gamma-reader相同的五项]
6. 仓位关联：当前持仓__，与本次结论的关系__
7. 宏观背景：今日__事件，对判断的影响__
8. 行为提醒：[如果触发了行为弱点，在此提醒；没有触发则省略此项]
9. 关联Setup：[如果有明显对应，点出Setup编号；没有则省略]
```

## 重要边界

- 第1部分的读图逻辑必须和 `spx-gamma-reader` 保持一致，如果后续发现读图逻辑需要改进，优先去改 `spx-gamma-reader`，这个skill自动跟着受益，不要在这里重复维护一套不同的读图标准。
- 第2部分的叠加是增量提示，不能喧宾夺主——如果图面信号很弱（比如处于区间中部"等待"状态），不要因为撞上了某个Setup就强行给出操作建议，Setup关联只是背景参考，不改变基础结论的方向判定。
- 查MEMORY和持仓信息时，如果信息已经明显过时（比如持仓部分写的是几个月前的标的，大概率已经平仓），要提示"MEMORY里的持仓记录可能已过期，建议先确认当前实际仓位"，不要默认它仍然有效。
