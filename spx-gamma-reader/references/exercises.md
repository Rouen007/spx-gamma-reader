# Bookmap 训练与反例

先认字段，再练观察，最后合图。以下全为合成情景，答案是证据边界，不是收益预测。

| 输入 | 应完成的判断 |
|---|---|
| 下方大挂单，未出现成交 | 可见流动性，不确认吸收/冰山 |
| 卖方成交增加、价格停滞，随后跌破下沿 | 起初承接候选，后续失效 |
| CVD -5000，价格上涨，无累积范围 | 同帧现象；查设置，不推断机构身份 |
| 两张 CVD 不同，后图刚重置 | 不计算净流量变化，不解释为撤单 |
| 亮带消失，缺成交/订单事件 | 流动性减少可见，撤单或成交消耗未知 |
| 紫色三角，插件未知 | 查官方文档，不默认冰山/止损 |
| 昨日 SPX 墙 + 今日 ES 图，无配对报价 | 分开解释，不沿用旧基差或平移墙 |
| 最终图显示反弹 | 事后路径，不能宣称早先已触发 |
| 同向持仓记忆来自一月前 | 过期，不据此建议加仓 |

每题输出可见事实、候选解释、缺什么证据、哪种反例会推翻。实图建同样的卡，保留不同意见与澄清，不只选成功样本。
