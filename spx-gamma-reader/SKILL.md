# Rouen SPX / Bookmap Reader

默认中文。结构地图 → 关键位附近的订单流 → 价格确认 → 条件路径。单图可独立分析，不要求齐全指标；缺项保留未知。背景不是触发，盘口不是未来价格保证。

## 接收证据

先记录交易日、图上时间/时区、收图时间、品种与期货合约、数据源、图类型、可见字段。日期不同的图不自动合并；仅时间相近也不证明同步。

- Dealer Heatmap：明确到期日期、0DTE/其他到期、局部与总 GEX、单位、来源构造；按列标题识别 0DTE。OI 自算、standard-gex 与 dealer-gex 各自解释。
- Bookmap：读 [Bookmap 查阅流程](references/bookmap.md)。先认面板与设置，再读挂单、成交、CVD、吸收/扫穿与价格位移。
- Footprint：有逐价 bid/ask 成交和 delta 才按 footprint 解释；普通成交量泡泡按实际字段命名。K线用于接受、拒绝、收回与回踩确认。
- SPX 与 ES：只有同刻配对报价和明确合约才记录基差；未知时各用自己的价位。不要用旧换算或期权 forward basis 替代实际 ES-SPX 基差。

多图先各自给一条可见事实，再列一致、冲突和时间缺口。过期 GEX 仅作旧地图，不按比例平移或推算新墙。无法识别的指标、插件符号和颜色先保留未知，按参考文档查阅；不用相似外观套另一插件定义。

## 判断与输出

1. 从当时价格结构暂判趋势、区间、失败突破或未确认；Gamma 正负只补充环境假设。
2. 选择附近候选反应区、中轴及下一目标。墙不是硬顶硬底，最亮带不是必然吸引。
3. 在候选区观察成交方向、位移和挂单变化。厚墙、CVD 背离、吸收标注都不能单独触发。
4. 列价格确认：接受外侧及回踩保持、收回及反抽失败、或仍反复穿越。说明固定使用的观察周期；不在不同周期之间挑有利证据。
5. 给出失效和第一目标；空间不足、信息冲突或确认缺失时明确等待。缺合约与报价时不把指数位移写成期权收益。

回答先给当前状态和关键条件，再展示依据：

```text
截止时刻 / 证据等级 / 数据缺口：
环境与附近候选区：
Bookmap：挂单 → 成交 → 位移；CVD设置与变化；插件状态：
价格确认：已发生 / 待发生 / 未确认
上行条件 / 下行条件 / 等待条件：
结构失效 / 第一目标：
来源分歧与下一次需要核验的变化：
```

不要强制给完整今日区间、方向或“可以动手”。不写未经验证的胜率，不能从单次盈利反推机制正确。

## 连续截图与复盘

按 [证据与台账](references/evidence-ledger.md) 冻结每次判断，保留节点迁移、原地增强、挂单变化、价格确认和上一假设失效时间。最终图只支持事后描述，不能补造早先可见性。

可用 `scripts/ledger.py check <record.json>` 检查时序与对齐，再用 `append` 写本地 JSONL。工具只检查数据契约，不读图、不判方向。原始群消息、私人截图和持仓留本地。

## Tuna 方法与查阅

结合 Tuna 时读 [来源与方法边界](references/tuna-framework.md)。保留环境 → 压力 → 结构 → 盘口 → 价格 → 风险的分工；区分本人原话、群友解释和本系统归纳。HIRO/COR1M 未提供时不编造，也不要求为齐全链路而购买数据。

训练与反例见 [练习](references/exercises.md)。个人事件、持仓与行为层通过相邻的 `spx-gamma-reader-with-memory` 调用，核心读图只在本文件及其引用维护。
