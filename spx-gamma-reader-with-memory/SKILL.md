# Rouen 个人上下文层

先执行 [基础读图](../spx-gamma-reader/SKILL.md)，仅增加下列检查；不另建读图标准。不在公开群聊或公共交付里输出私人仓位与行为记录。

## 事件

使用可核验的事件日历及事件时间，写明事件前/后和证据时点。事件临近时重新评估结构假设与滑点，不默认所有新闻日只能趋势，也不根据历史新闻猜当日催化剂。

## 持仓

只用用户提供或明确授权来源的仓位；记录 `position_as_of`、标的、完整期权腿、到期、数量与最大损失。缺项标未知，不自动读取任意 MEMORY 文件或账户。

方向一致只说明同向暴露，不构成加仓依据；检查期限、组合 Greeks、相关集中度、事件与流动性。方向相反先区分对冲、独立策略或原假设失效，不默认应该平哪一边。指数结构止损与权利金风险分别表达。

## 个人纪律

仅引用用户已经确认的规则、实际当前状态和可追溯案例。作者的 Setup 编号、持仓或行为标签不迁移给用户。背景、Setup 或情绪提醒不能把基础层的“等待”变成“触发”。

## 追加输出

```text
事件：来源、时间与对本次判断的影响
持仓：证据时点、已知暴露、冲突与缺项
个人纪律：确实适用的一条规则（无则省略）
结论变化：哪些条件被限制；基础触发是否仍未发生
```

个人证据保存本地，发布只用抽象规则和匿名合成例子。
